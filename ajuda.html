Ajuda do Sistema

Este sistema web foi desenvolvido para permitir o cadastro de clientes e pets, além do agendamento de serviços do petshop.

Funcionalidades disponíveis

  • Visual estilizado com CSS e Bootstrap
  • Carrossel de imagens na página inicial
  • Cadastro de cliente com dados pessoais
  • Cadastro do pet com nome, raça e idade
  • Escolha de serviço: banho ou tosa
  • Escolha do método de atendimento: tele-busca ou entrega no local
  • Agendamento com data e horário
  • Validação básica dos dados com JavaScript
  • Mensagem de confirmação do agendamento
  • Uso de acessibilidade com textos alternativos nas imagens

Como usar

  1. Acesse a página inicial.
  2. Preencha os dados do cliente.
  3. Preencha os dados do pet.
  4. Selecione o serviço desejado.
  5. Escolha a forma de atendimento.
  6. Defina a data e o horário.
  7. Clique em Agendar serviço.
